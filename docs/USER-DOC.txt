Cerebro — Agent candidat (Xavier)
===================================

Un seul fichier exécutable, rien à installer. Le runtime .NET est intégré dedans.

Ce que le système d'exploitation va afficher au premier lancement
-------------------------------------------------------------------

Cet exécutable n'est pas signé par un éditeur reconnu (outil interne à l'école). Windows et macOS vont afficher un avertissement la première fois — c'est normal, suivez les instructions ci-dessous selon votre système.

WINDOWS
  - Double-cliquer sur xavier.exe déclenche "Windows a protégé votre ordinateur" (SmartScreen).
  - Cliquer sur "Informations complémentaires", puis "Exécuter quand même".

MACOS
  Un double-clic affiche "xavier ne peut pas être ouvert car il provient d'un développeur non identifié".
  Deux façons de contourner :
    - Clic droit (ou Ctrl+clic) sur xavier > Ouvrir > confirmer "Ouvrir" dans la boîte de dialogue (à ne faire qu'une fois).
    - Ou, dans un Terminal, depuis le dossier où se trouve l'exécutable :
        chmod +x ./xavier
        xattr -d com.apple.quarantine ./xavier
        ./xavier

LINUX
  Rendre l'exécutable lançable puis le lancer, depuis un terminal :
        chmod +x ./xavier
        ./xavier

Configuration (pour le surveillant)
------------------------------------

L'URL du serveur et l'empreinte du certificat sont les mêmes pour tous les candidats d'une session
— les faire saisir à la main est source d'erreurs (l'empreinte est un long code hexadécimal).

Pour les pré-remplir : éditer xavier.config.json (déjà présent à côté de l'exécutable dans
l'archive) et y indiquer l'URL et l'empreinte réelles du serveur pour la session du jour :

  {
    "serverUrl": "https://192.168.1.10:8443",
    "certThumbprint": "A1B2C3D4E5F60718293A4B5C6D7E8F901234567"
  }

Distribuer ensuite l'exécutable accompagné de ce fichier xavier.config.json aux candidats.
Si le fichier est absent, l'agent redemande ces informations comme avant (rien de cassé pour un
usage sans configuration préalable).

Utilisation
-----------

Lancer l'exécutable sans argument : il demande successivement :
  1. l'URL du serveur (ignoré si déjà présent dans xavier.config.json — voir ci-dessus)
  2. le code de session (communiqué par le surveillant)
  3. votre identifiant candidat (le vôtre, communiqué par le surveillant)
  4. si l'URL est en HTTPS, l'empreinte du certificat du serveur (ignoré si déjà présent dans
     xavier.config.json — laisser vide si demandée et non applicable)

Une fois connecté, l'agent tourne en arrière-plan pendant toute la durée de l'épreuve : ne pas le fermer avant la fin annoncée par le surveillant.
En cas de problème (message d'erreur, refus de connexion), contactez immédiatement le surveillant avant de continuer l'épreuve.
